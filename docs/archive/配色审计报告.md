## 五、收敛策略建议

- **黑白灰/透明层（绝大多数）**：替换为 CSS 变量——`--border`/`--border-weak`/`--bg-panel`/`--bg-hover`/`--input-bg`/`--card-bg`/`--text-2` 等，深浅主题自动取正确值
- **半透明叠加**（`rgba(0,0,0,0.x)` 背景）：深色设计残留模式，统一改为 `color-mix(in srgb, CanvasText x%, transparent)` 或对应变量
- **亮蓝 `#38bdf8` 等旧 accent**：替换为 `var(--accent)`（系统主题下=AccentColor，自定义主题下=原亮蓝）
- **收敛后**：全站不再有主题相关硬编码，只剩业务语义色与遮罩/阴影，三套主题零穿帮

- **实际替换去向**：

  - 强操作按钮深底（pdf-action 0.78 / pdf-enlarge 0.82） → `var(--bg-elev-2)`
