## 三、元素设计规范（要套用的部分）

### 3.1 背景层级：实色分层，禁止半透明叠加

| 层级 | 用法 | token |
|---|---|---|
| 页面底 | 应用最底层（规格书要求纯色，去径向渐变） | --bg |
| 卡片 / 面板 / 侧栏 / 表格容器 | 所有实体容器一律实色 | --bg-elev |
| 卡片内列表项 / 表头 / 缩略图底 / 轨道 | 容器内再抬一档 | --bg-elev-2 |
| 悬停 | 行、可点项 hover | --bg-hover |

> 💡 **--bg-panel（半透明白 2.5%）不得用于实体容器。** 本项目 .glass-inner / .template-manager-v4 用它做容器底，两层半透明叠加出 #1E2022，与表格 #161719 形成色差补丁——这正是 REQ-037 标签栏"表头没改"的根因。

### 3.2 哑光金（accent）使用规则：全界面最克制的颜色

| 场景 | 参考规范 | 本项目现状 |
|---|---|---|
| 页面/区块唯一主操作按钮（新建、添加物料、上传） | 金色实心：accent 底 + accent-text 深字，圆角 6px，12-13px，padding 6-7/14 | 基本符合，但圆角/尺寸不统一（10px/14px 混用） |
| 选中态（侧栏导航、分类树、筛选 chip） | **accent-soft 弱底 + accent 文字**，导航可加 3px 金色左竖条；chip 为胶囊+accent 边框 | **不符**："上装"徽标用了金色实心块（accent 底+深字），在深色区突兀 |
| 状态 / 类别徽标 | 胶囊（圆角 999）：状态色文字 + 同色 12-15% 弱底；中性用 bg-hover-2 | 徽标形态/底色不统一，部分用金块 |
| 设置页次要添加（+ 添加品牌/人员/部位） | **虚线幽灵按钮**：透明底 + 1px dashed border + text-3 文字 | "新增部位"为金色实心按钮，与参考不符 |
| 次级操作（导出、存入预设、历史版本） | input-bg 底 + 1px border + text-2，圆角 6 | 样式不统一 |
| 危险操作（删除） | 红 10% 底 + 红 30% 边框 + #f43f5e 文字 | 需统一 |
| Tab 激活、输入 focus、进度点、合计金额、图表填充 | 金色下划线 / 金色小点 / 金色文字，不铺色块 | 部分符合 |

### 3.3 卡片

- bg-elev 实色 + 1px var(--border) + 圆角 10px（批次卡 8px）+ padding 14-24px。
- 静态卡不投影；可点卡片 hover 时边框升级 border-strong（参考另加了浮起阴影，见决策点 D4）。
- 卡片标题 13px/500/text；卡片内列表项 bg-elev-2 + 圆角 6 + padding 8/10。

### 3.4 表格（无框 Data Grid 风格）

- 表头：bg-elev-2 实色 + text-3、11-12px/500、padding 8px；左对齐。
- 数据行：透明底 + 1px border-weak 底线 + hover bg-hover；单元格 padding 6-10、13px。
- 行内输入框：透明无框（弱化"满屏输入框"的压抑感），hover 单元格出 bg-hover，focus 出 1px 金色下划线。
- 款号 / 版单号 / 数值列用等宽字体 DM Mono；序号列 text-4；小计/合计列 accent 色 600 字重。
- 表格容器 bg-elev；冻结列必须用同级实色背景，不得透明（REQ-038 穿透问题同源）。

### 7.2 REQ-037 / REQ-038 根治证据

> ⚠️ **2026-09-16 晚用户实测结论更正**：以下为开发侧 CDP 自测证据与批6-10 的改动过程记录。**用户实测判定数据穿透"技术修复无效"**——实际应用内滚动时数据仍穿透显示，此前的"根治收口"结论不成立，予以推翻。接手者须先复现穿透场景做根因级修复，不能以 CDP 自测代替用户实测。本节仅保留为改动历史。

**REQ-037（设置页表格"补丁"/穿透）**：根因是 template-manager-v4 大容器与 glass-inner 双层半透明（--bg-panel）叠加，比表格实色亮一档。批9 将大容器/左侧栏/标签栏/表格容器全部改实色 bg-elev，CDP 实测四者背景严格同色（custom rgb(22,23,25)、dark rgb(18,18,18)、light rgb(255,255,255)）；批10（5ff655e）进一步按参考原型收口——表头由 bg-elev-2 亮一档改回与容器同色 bg-elev 不透明（用户从批7 起否决的补丁亮条消除，sticky 不透明背景继续保证滚动穿透裁剪），数据行改 bg-elev-2 圆角胶囊行（圆角6+行间 4px 间隙+hover 整行高亮），公差/放码金色标签改透明 text-3 纯文字小字（对齐参考"±1cm"）。三主题 CDP 冷加载实测：表头与容器严格同色、滚动穿透保持。

**REQ-038（列表冻结列"黑色阴影"边缘）**：根因是列表表格原本没有卡片容器、直接铺在页面底（custom 还有径向渐变）上，冻结列 th/td 内联实色与非冻结透明区形成色差边缘。批9 将列表收进 .list-view-scroll 实色 bg-elev 卡片（1px 边框 + 圆角 10），冻结单元格抽 .sticky-cell 类（静态与卡同色、右缘仅 1px 弱分隔线、hover 用不透明 bg-elev-2 防滚动内容穿透），视觉属性全部从 JSX 内联抽到 CSS（position/left/z-index/宽度/padding 等布局内联全保留）。横滚 300px、951px 窄视口横滚、行 hover、三主题 CDP 冷加载实测：冻结列与卡片严格同色、无阴影带、hover 全行贯通不穿透。

**顺带挖出的隐藏根因**：base.css 旧别名块 :root 中 --glass-bg: rgba(22,23,25,.75) 源序晚于 theme.css，把三主题 token 全覆盖（dark/light 靠高特异性规则幸免，custom 所有 .glass 实际一直是 75% 半透明，浮层上内容穿透）；已改为 var(--bg-elev)，操作日志等裸 .glass 弹窗在三主题下全部实色。
