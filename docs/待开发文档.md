# 待开发文档

> 本文件是 golden-shuttle 项目的开发需求登记处。
> - **记录**：在本对话（需求登记会话）中提交需求，由助手写入本文件。
> - **执行**：实际开发在其它对话中按本文件发起指示，不在本对话进行。
> - 每新增一条需求时，编号递增；状态变化时直接修改对应条目。
